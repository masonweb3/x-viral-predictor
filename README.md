# x-viral-predictor

## 这是什么

发帖前给同一条帖的几版稿打分，比哪版更可能爆；发出 12 小时后再看一眼浏览，推算最终能不能过 3 倍。

"爆"的定义：浏览数达到该作者近期中位数的 3 倍以上。每条稿一次 Jev（typesafe.ai）请求问 33 个问题，再用岭回归权重加总成预测倍数。单文件，Python 3.9+，只用标准库。

## 准不准

自带权重用 23,894 条帖、49 位作者训练，按作者留一（每次拿一位作者当测试集）的 Spearman ρ 为 0.244，作者内中位 ρ 为 0.307。下表是留一预测落在各档时，历史上真过 3 倍的比例：

| 预测倍数 | n | 真过 3 倍 |
|---|---|---|
| <1.00 | 7,840 | 10.3% |
| 1.00–1.26 | 6,379 | 17.5% |
| 1.26–1.58 | 4,947 | 21.9% |
| 1.58–2.00 | 2,959 | 27.9% |
| 2.00–2.24 | 830 | 38.0% |
| 2.24–2.51 | 468 | 38.2% |
| 2.51–2.82 | 292 | 43.5% |
| ≥2.82 | 179 | 44.7% |

说白了：只能排序、避雷，不能预言。预测倍数最高的那档也有一半多没过 3 倍。小号和单个作者上更不准；只读文字，不看图。

## 三步用法

1. 去 https://console.typesafe.ai/keys 开一个 key，`export JEV_API_KEY=…`（或写进当前目录的 `.env`）。
2. 直接打分，用自带权重：`python3 xviral.py score 稿1.txt 稿2.txt`
3. 想训自己赛道的：把 `authors.example.txt` 复制成 `authors.txt`，填 20–50 个同赛道账号，然后
   `python3 xviral.py pull --authors authors.txt`，再 `python3 xviral.py train`。训练前会显示要问的条数和预计费用，确认后才开始；之后 `score` 自动用 `xviral-data/model.json`。

发后 12 小时起：`python3 xviral.py early https://x.com/某人/status/123…`，按发帖时长折算最终浏览，对比该作者近期中位。不到 12 小时会提示太早。

`python3 xviral.py selftest` 是离线自检。数据放在 `./xviral-data/`，用环境变量 `XVIRAL_DIR` 可改。

## 费用

打一条约 $0.0003；训 1 万条约 $2.6（每条约 6,300 输入 token，$0.042 / 百万 token，按实际 token 计）。

## 自带权重是哪个赛道

中文 X 的海外卡、港卡 / 海外银行、eSIM / 海外号、AI 工具订阅、全球八卦。别的赛道请改 `xviral.py` 里的 `READER`（读者描述），再自己 `train`；`READER` 和模型里记的不一致时，`score` 会警告。
